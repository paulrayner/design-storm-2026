# Water system 3D map: source data

Data behind `../design-storm-water-system-3d.html`, a laymen-first 3D satellite
view of Denver Water's collection system: reservoirs, river gauges, SNOTEL snow
stations, treatment plants, and the tunnels that cross the Continental Divide.

## Viewing the map

```
python3 eddd/data/serve.py
open http://localhost:8765/design-storm-water-system-3d
```

Needs a network connection: satellite imagery (Esri), terrain tiles
(Mapzen/AWS), and the live station charts (USGS, NRCS) all stream in. The page
also reads basin polygons and river lines from `../strontia-brief/basins/`, so
those two directories travel together.

## What is here

| Path | What it is |
|------|-----------|
| `system.json` | Generated. Every point and line the map shows, with plain-language blurbs and chart endpoints. Do not edit by hand. |
| `build_system.py` | Regenerates `system.json` from `../strontia-brief/places.json` plus the files below. Offline. |
| `snotel-co-stations.json` | NRCS AWDB metadata for all 118 active Colorado SNOTEL stations, pulled 2026-08-31. |
| `storage-history.json` | Generated by `fetch_storage_history.py` (network). Full daily reservoir storage from the DWR CDSS API, folded into per-water-year traces plus a median, behind the historical overlay chart. |
| `fetch_storage_history.py` | Refetches the storage history. Rerun rarely; see its docstring. |
| `snotel-history.json` | Generated by `fetch_snotel_history.py` (network). Full daily SWE history for the mapped SNOTEL stations from the NRCS AWDB API, folded the same way, behind the snow-station overlay chart. |
| `fetch_snotel_history.py` | Refetches the SNOTEL history. Run build_system.py first if the station set changed. |
| `strontia-plume.json` | Generated by `build_plume.py` (offline, needs openpyxl) from `../data/Strontia 0407_0819.xlsx`, `../data/USGS_South_Platte.csv`, and `../data/FoothillsInfluent.csv`. Daily median turbidity by 2-unit depth bin in Strontia Springs Reservoir for Aug 8 to 19, 2026, with the river gage daily maximum and the plant's TOC and alkalinity for the same days. Drawn during the storm replay; method matches `../design-storm-strontia-plume.html`. |
| `foothills-influent.json` | Generated by `build_system.py` from `../../design-storm/data/FoothillsInfluent.csv` (offline). Daily TOC and alkalinity arriving at the Foothills plant, shown in its detail panel. |
| `foothills-predictions.json` | Generated by `build_predictions.py` (offline) from `../experiments/rolling/results/predictions-*.csv` (the experiments directory is local working material, not on the public tip). Per-day out-of-sample predictions of TOC and alkalinity from the rolling-origin evaluation, one trace per model (random forest, CatBoost) plus the actual series, with the excursion threshold for each. Drawn over the influent record. |
| `build_predictions.py` | Rebuilds `foothills-predictions.json`. Run `.venv/bin/python -m rolling.predict` from `../experiments` first if the models or data changed. |

## Where the coordinates come from

- Gauges and reservoirs: `../strontia-brief/places.json` (USGS site records).
- SNOTEL: `snotel-co-stations.json`, filtered to stations whose coordinates
  fall inside the four basin polygons in `../strontia-brief/basins/`, so every
  snow pillow shown drains to a gauge that is also shown.
- Ralston Reservoir, Northwater and Moffat plants, Moffat Tunnel portals:
  OpenStreetMap, way ids recorded on each entry in `build_system.py`.
  The Moffat water tunnel is drawn between the rail-tunnel portals it
  parallels; the west portal matches USGS gage 09023562 within 70 m.

## Live chart endpoints

- Gauges: `https://waterservices.usgs.gov/nwis/iv/` (15-minute values, last 7
  days; parameter per station in `system.json`). CORS-open.
- SNOTEL: `https://wcc.sc.egov.usda.gov/awdbRestApi/services/v1/data` (daily
  snow water equivalent for the current water year). CORS-open.

## Refetching the SNOTEL station list

Rarely needed; station metadata is close to static.

```
curl "https://wcc.sc.egov.usda.gov/awdbRestApi/services/v1/stations?stationTriplets=*:CO:SNTL&activeOnly=true" -o snotel-co-stations.json
python3 build_system.py
```
