# Team Education: inside Strontia Springs Reservoir during a storm

Turns Denver Water's sonde data into a playful lesson for children.

Open `index.html`. It is self-contained: the summer scene with the quiz, and a
second tab framing the two data pages below.

| Artifact | What it is |
|---|---|
| `index.html` | The summer page. Generated by `build.py` from `template.html` and `sonde_data.py`. |
| `map/strontia.html` | Strontia Springs, by depth: the lessons and the Explore heatmaps. Serve the repository to open it on its own. |
| `map/prediction-dashboard.html` | The Foothills TOC and alkalinity prediction dashboard. Serve the repository to open it on its own. |
| `map/design-storm-water-system-3d.html` | The 3D map with the Strontia depth panel. |
| `FINDINGS.md` | The findings behind the lessons, each with its number and script. |
| `analysis/`, `dashboard/` | The scripts that generate the pages' data files. |

Rebuild the summer page after changing anything it inlines:

```
uv run --with pandas --with openpyxl teams/team-education/build.py
```

The "Ask Claude" buttons need `python3 teams/team-education/chat_server.py` running from
the repository root instead of `serve.py`.
